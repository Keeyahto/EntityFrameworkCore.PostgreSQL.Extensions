# EntityFrameworkCore.PostgreSQL.Extensions

Библиотека предоставляет типизированный доступ к механизмам PostgreSQL через EF Core: согласование конкурентной работы, вставку строки с пропуском выбранного уникального конфликта, чтение серверного времени и проверку требований к базе данных.

Библиотека содержит одну сборку для `net10.0` и использует пространство имён `EntityFrameworkCore.PostgreSQL.Extensions`. Руководства описывают **0.1.0-preview.4**. Доступность пакета в публичном NuGet не подтверждена; в [начале работы](getting-started.md) показаны сборка и установка локального пакета. API предварительной версии может меняться.

<a id="shared-boundaries"></a>
## Общее поведение

Вы создаёте и завершаете транзакции. Блокировки строк и advisory-блокировки требуют текущую явную транзакцию EF; вставку с пропуском конфликта и чтение серверного времени можно выполнять самостоятельными SQL-операторами. Отмена передаётся PostgreSQL, ошибки провайдера сохраняются. Библиотека не добавляет повторные попытки или правила восстановления приложения.

Для запросов с блокировкой строк разрешён ограниченный набор форм. Запрос с маркером блокировки за его пределами завершается явной ошибкой. Обычные запросы сохраняют штатное поведение EF/Npgsql. Перед сочетанием блокировок с другими операторами LINQ прочитайте соответствующее руководство.

Опорное сочетание зависимостей и сервера, а также непроверенные конфигурации перечислены в [разделе о совместимости](compatibility.md). Библиотеку можно развивать и использовать независимо от конкретного приложения.
