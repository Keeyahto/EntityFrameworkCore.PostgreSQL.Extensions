# Security

The repository is public and licensed under Apache-2.0. A private vulnerability reporting channel and response commitment have not been established. Maintainers should configure GitHub's private vulnerability reporting or another verified private channel before a package release, then update this file with the reporting path and any actual response policy.

Do not post credentials, connection strings, or private database contents in public issues. Diagnostics and reports should redact secrets and sensitive parameter values. Preserve required third-party notices; unresolved attribution conflicts block copying affected material.
