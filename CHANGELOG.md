# Changelog

## Unreleased

The repository contains experimental EF Core/Npgsql APIs for row locking, transaction-scoped advisory locks, atomic insert-ignore, PostgreSQL clock mapping, and read-only capability discovery. Query locking retains three selectable comparison carriers. Bounded local PostgreSQL checks cover specific root-query, ordering/limit, compiled-query, and fail-closed rejection forms; these checks do not select a production carrier or establish a supported compatibility range. No released package is available. Detailed verification records belong with the change evidence.
